# Original Data Source

## Nigeria Geological Survey Agency Mineral Resources Map of Nigeria

The mineral occurrence information in this database was derived from the:

**Nigeria Geological Survey Agency (NGSA). (2023). _Mineral Resources Map of Nigeria_.**

The NGSA 2023 map is the principal external source used for identifying and compiling the mineral occurrence records represented in this database.

### Official NGSA Source

Official map:

https://ngsa.gov.ng/wp-content/uploads/2023/08/Mineral_Resources_Map_of_Nigeria_2023.pdf

NGSA geological maps:

https://ngsa.gov.ng/geological-maps/

NGSA official website:

https://ngsa.gov.ng/

## Source Format

The source material used for the database compilation was available as a **PDF map**.

No structured spreadsheet, CSV, shapefile, GeoJSON or equivalent machine-readable mineral-occurrence database was used as the source for the original compilation.

The PDF map presents mineral occurrence localities and associated mineral/resource information in cartographic form. The information required for the database was therefore manually interpreted, extracted and transcribed from the map.

## Source Description

The NGSA Mineral Resources Map of Nigeria presents the geographical distribution of identified mineral occurrences across Nigeria.

The map provides mineral occurrence information, including locations and associated mineral/resource types represented through the cartographic symbols, labels and codes used in the source product.

The database in this repository represents a structured tabular compilation of information interpreted from that source map.

## Original Database Creation

The original Excel database was created **from scratch by whoisOlaxtra** using the NGSA 2023 map as the source document.

The original compilation involved:

1. examining the NGSA PDF map;
2. identifying mineral occurrence localities represented on the map;
3. extracting associated mineral/resource types and codes where applicable;
4. manually transcribing the identified information;
5. organising the extracted information into a structured Excel workbook; and
6. establishing the database structure used for the compiled records.

## Subsequent Database Review and Update

After the original database had been created, the workbook was subsequently reviewed against the NGSA 2023 map to assess whether occurrence records represented in the source map had been omitted during the initial compilation.

The review involved:

1. examining the source map alongside the original database;
2. checking mineral occurrence localities and associated resource information;
3. identifying records not captured in the initial database;
4. manually extracting the identified records from the source map;
5. adding the identified records to the workbook;
6. retaining the established workbook structure and formatting; and
7. preserving source terminology and occurrence codes where applicable.

The resulting workbook therefore represents an updated structured compilation of mineral occurrence information manually extracted from the NGSA source map.

## Important Note

This database is a secondary structured compilation derived from the NGSA source map.

It should not be treated as an independent geological survey, an official NGSA database, or a replacement for official NGSA information.

The database represents mineral occurrence information interpreted and transcribed from a cartographic source and may therefore inherit limitations associated with the source map and the manual extraction process.

Users requiring authoritative, current or more detailed geological and mineral-resource information should consult the Nigeria Geological Survey Agency and its official publications and datasets.
